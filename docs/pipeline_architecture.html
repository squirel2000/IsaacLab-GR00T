IsaacLab-GR00T · N1.7

Fine-tune → Deploy Automation Pipeline

One resumable command waits for a free H100, fine-tunes GR00T on the remote Pegasus box, pulls the verified checkpoint home, hops Wi-Fi to deploy it onto the asus-4090 sim box, and writes an offline report — surviving any disconnect along the way.

IDLE → GPU_WAIT → TRAINING → EVAL → DOWNLOADING → DEPLOYING → REPORTING → DONE
control flow data flow (animated = live) Wi-Fi switch read-only monitor

One entry point

scripts/gr00t_pipeline.py is the single CLI — a thin dispatcher with one shared implementation per behavior (nothing reimplemented). For example:

python scripts/gr00t_pipeline.py run        # resume (or start) the full pipeline
python scripts/gr00t_pipeline.py dashboard  # read-only live web UI at http://localhost:8770

Other subcommands: run --reset, status, stop, finetune …. Full reference + how to turn on EVAL: scripts/pipeline/PIPELINE.md.

Stage by stage

gpu_monitor.py

GPU_WAIT

Polls nvidia-smi on Pegasus until a GPU is idle (util<10% & mem<5 GB). gpu_priority orders candidates (e.g. prefer GPU 1); force_gpu hard-pins one.

training_monitor.py

TRAINING

Launches the fine-tune detached (setsid+nohup) so it survives a laptop disconnect, then tails run.log into metrics.jsonl. On resume it re-attaches if still running, else relaunches and the HF Trainer auto-resumes from the last checkpoint.

eval_runner.py

EVAL gated

Runs scripts/eval/run_eval.py detached on the H100 (closed-loop IsaacSim), polls the combined-episodes log, records the success rate, and fetches the SVG chart. No-op unless eval.enabled — keeps the pipeline working until the H100 eval env is ready.

downloader.py

DOWNLOADING

Pulls the inference-ready checkpoint home over HTTP range requests — resumable and sha256-verified; the zip excludes checkpoint-*/ (~half the transfer).

deployer.py · net_util

DEPLOYING

Switches Wi-Fi to the OMAP LAN, then SFTP-pushes the checkpoint to the asus-4090 over paramiko SSH and unzips it remotely. Retries on transient SSH/network errors.

report_generator.py

REPORTING

Writes an offline report_*.html with run metadata and an inlined Chart.js loss curve (full curve across resumes) — no external assets, opens anywhere.

net_util · finalize

↩ back online

After deploy, restores internet by dropping the LAN and letting the enterprise SSID auto-reconnect — verified by ping, not by the flaky netsh SSID read; warns loudly if it cannot.

EVAL stage — how eval_runner works

Closed-loop IsaacSim eval on the H100, gated by eval.enabled. Detached like training, so it survives a laptop disconnect.
